# Odd Hours pipeline: วิธีทำตอนใหม่

ทุกอย่างรันจากโฟลเดอร์นี้ ใช้ Python 3, Node + Playwright (Chromium), ffmpeg และ espeak-ng (เสียงชั่วคราว)

## โครงสร้าง
- `oddhours/`: แผ่นตัวละคร (`james.html`, `tawan.html`, `cat.html`) เป็นต้นฉบับของรูปทรงและสีตัวละคร
- `sb/`: ชิ้นส่วนฉากกับสไตล์ภาพ (`build.py`, `style.py`, `all8.py`, `all12.py`) ห้องนอน ทางเดิน แสง ฝุ่น และเกรน
- `v2/`: ตัวสร้างคลิปแบบเคลื่อนไหวของตอนที่ 1 ใช้เป็นแม่แบบของตอนต่อไป
  - `v2.py` + `v2.js`: ฉาก การเคลื่อนไหว ซับ และกราฟิก
  - `timeline.py`: จัดเวลาจากความยาวเสียงพากย์ และมิกซ์ดนตรีกับเสียงประกอบ
  - `dub.py`: พากย์ด้วย ElevenLabs (เสียงเจม `S2oNPNuiP27Jy2lVX5uZ`, ตะวัน `IM6pYHlwZQDuZqGBrSYI`) ตั้งเพดานเครดิตไว้ในสคริปต์
  - `render_all.js`: เรนเดอร์ทุกเฟรม · `assemble.sh`: ใส่ grade, เกรน, เสียง และต่อ `outro.mp4`
  - `outro.py`: ฉากโลโก้ปิดท้ายที่ใช้ทุกตอน
- `../cover/`: แม่แบบปก (`cover.py` → `render_cover.js` → `../out/cover.png`)

## ขั้นตอนทำตอนใหม่
1. เขียนบท แล้วส่งให้เจ้าของช่องตรวจก่อน
2. ทำภาพนิ่งทุกช็อตให้ตรวจ ใช้ฉากและตัวละครจาก `v2.py` เพิ่มหรือแก้ฉากใน `SV[...]`
3. แจ้งเครดิตก่อนพากย์ทุกครั้ง แล้วรัน `dub.py` แปลงเสียงเป็น wav ไว้ใน `vo2/`
4. `python3 timeline.py` → `python3 v2.py` → `node render_all.js` → `bash assemble.sh`
5. ทำปก: แก้ `EP` กับ `ART` ใน `cover/cover.py` แล้วเรนเดอร์

## ข้อควรรู้
- คีย์ ElevenLabs เก็บไว้ใน Network secrets ของ environment (ใส่แบบ Bearer token) ไม่ได้เก็บในไฟล์
- ชิ้นส่วนที่ใช้ร่วมกันผ่าน `<use>` เช่น กะพริบตาหรือปาก ต้องเปิดปิดด้วย attribute `display` ที่ชิ้นต้นฉบับ ใช้คลาส CSS ไม่ได้ผล
- ดนตรีต้องอยู่ในย่านเสียงกลาง เพราะลำโพงมือถือเล่นเสียงทุ้มต่ำมากไม่ออก ให้เพลงเบากว่าเสียงพูดราว 8–10 dB และหนักเบาตามเรื่อง
